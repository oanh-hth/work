# Part 11: Make it yours

In Part 10 you chose each part of the room from a list. Here the lists stop being the limit: your own colours, things where you want them and the size you want, your own pictures and a poster you draw, and new items that open as you record decisions. The part ends with what every app needs once people use it: getting a new version to them.

## Knowledge check

Tick each box (change `[ ]` to `[x]`) when you can explain it in your own words. `npm run progress` counts them.

- [ ] I can read and write a colour as hex, and change its brightness channel by channel
- [ ] I can turn a movement on the screen into a movement in a scaled drawing
- [ ] I can explain why every drag feature also needs a way to do the same without dragging
- [ ] I can say when to change the DOM directly instead of through React state, and what to do afterwards
- [ ] I can shrink a picture in the browser, and say why it must happen before saving
- [ ] I can model a drawing as data and get undo for free
- [ ] I know what `position: fixed` is fixed to, and when a portal is the fix
- [ ] I can derive what is unlocked from a count, without storing a list of unlocked things
- [ ] I can explain how a service worker updates, and how to check that a deploy really went out
